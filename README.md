
# Future Skills Learning Center

## Community Learning Center Website

### Project Overview
Future Skills Learning Center is a community-based learning organization that provides practical learning opportunities to help individuals develop skills for education, employment, entrepreneurship and personal growth.

This project is a multi-page website developed using HTML5. It demonstrates the use of semantic HTML, accessible forms, multimedia elements, tables and embedded content.

### Project Objectives
- Provide information about the learning center.
- Present available courses and learning programs.
- Allow prospective learners to complete a registration form.
- Provide contact information and a way to send inquiries.
- Demonstrate correct HTML5 structure and accessibility practices.

### Website Pages

1. **Home:** Introduces the learning center and its services.
2. **About Us:** Explains the center's mission, vision and values.
3. **Courses:** Displays available courses and learning resources.
4. **Registration:** Provides a form for prospective learners.
5. **Contact:** Provides contact information and a message form.

### Technologies Used
